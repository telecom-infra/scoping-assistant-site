Beta research tool: Results are based on available reference data and automated location research. Results may be incomplete or outdated. Verify jurisdiction, exchange, engineering, and permitting requirements before submission.
Work Disclaimer: This tool is intended to assist with research and scoping only. It does not determine final jurisdiction, permitting requirements, engineering requirements, or other project decisions. Final verification and decisions remain with the permit specialist.

The browser transfer tool is intentionally separate from this application. It only transfers selected project fields into Anvil; it does not create or submit the project. Developer install is required for this beta build.
How does this work?
1. Complete and review the project in the Scoping Assistant.
2. Install the small Edge or Chrome transfer extension using the developer-install instructions in its package.
3. Choose the fields to transfer in the extension.
4. Open Anvil and go to the Create Project page.
5. Click Create New Project in Anvil here to hand off the current project data.
6. Transfer the selected fields in the extension, review the populated Anvil form, upload files, add anything missing, and then create the project in Anvil.
The transfer tool uses the current values in the Scoping Assistant, whether they were auto-detected or manually edited.
